## 简介

DSCode 是一款本地优先、开源的编程代理。本《隐私政策》说明 DSCode 命令行工具与 dscode.ai 网站如何处理您的数据。

一句话总结：**DSCode 本地优先，不收集任何遥测数据。** 您的会话、配置与 API key 都保存在您自己的机器上。您的数据离开电脑的唯一情形，是您主动选择将其发送给 DeepSeek 等 AI 服务商时。

## DSCode CLI 如何处理您的数据

### 仅存储在您本机

使用 DSCode CLI 时，以下数据只存储在您的电脑上：

1. **会话** —— 您与代理的对话历史，以本地树形 JSONL 文件形式存储在 `~/.dscode/` 目录下。
2. **API key** —— 您的 DeepSeek（或兼容网关）API key，存储在 `~/.dscode/agent/auth.json`，权限为 `0600`，只有您的用户账户可以读取。
3. **配置** —— 端点与设置保存在 `~/.dscode/config.json`。
4. **检查点** —— 工作过程中创建的补丁检查点，保存在您仓库的本地 Git 历史中。

### 仅在您使用时发送给 AI 服务商

DSCode 的工作方式是：将提示词（包括您仓库中的代码）发送给您配置的 AI 服务商（默认为 DeepSeek）。这只会发生在您实际运行代理时。这些数据的处理受该服务商自身条款与隐私政策的约束，而非本政策。

### 无遥测

DSCode 不会自动上报数据。它不包含任何分析、崩溃上报或自动更新机制来传输您的数据。源代码完全开放，可在 [GitHub](https://github.com/thinkany-ai/dscode) 上审查。

## dscode.ai 网站如何处理您的数据

dscode.ai 是一个静态营销网站。我们不需要注册账号，除标准 Web 服务器日志（如 IP 地址、浏览器类型、访问页面，用于保障站点安全与了解整体流量）外，不收集访客的个人信息。

如果您选择安装或使用 DSCode CLI，我们不会收到任何关于您的使用情况、仓库或 API key 的信息。

## 数据共享

我们不出售、出租或交易您的个人信息。仅在以下有限情况下共享数据：

- 与您主动配置的 AI 服务商（如 DeepSeek）共享，以提供您请求的服务。
- 为遵守法律义务或响应公共机构的合法请求。
- 为保护我们的权利、财产或安全，或我们用户的权利、财产或安全。

## 数据安全

您的本地数据由操作系统的文件权限保护（API key 使用 `0600` 权限）。数据发送给 AI 服务商时，通过加密的 HTTPS 连接传输。由于 DSCode 是开源的，您可以审计软件对数据的每一次处理。

## 您的权利与控制

由于数据保存在您自己的机器上，您始终拥有完全的控制权：

- 随时删除 `~/.dscode/` 目录以清除会话与配置。
- 随时通过服务商控制台吊销您的 API key。
- 审查代码 —— DSCode 的所有行为都在公开仓库中可见。

## 儿童隐私

DSCode 是一款面向成年人的开发者工具。我们不会有意收集儿童的个人信息。

## 本政策的变更

我们可能不时更新本《隐私政策》。重大变更会通过更新本页顶部的日期体现。由于 DSCode 是开源的，软件处理数据方式的任何变化也始终在代码中可见。

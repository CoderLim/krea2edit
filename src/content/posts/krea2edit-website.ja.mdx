**Krea2 Edit**（https://krea2edit.app）は、ひとつの目的のために作られた小さなサイトです。クリエイターに、コミュニティの identity-edit ワークフローへ向かう、安定して検索しやすい拠点を提供します。Hugging Face のディスカッション、Space の URL、ComfyUI のインストール手順を先に探し回る必要はありません。

このページでは **サイト自体** について説明します。何のためにあるのか、何が載っているのか、生の Space リンクより Krea2 Edit をブックマークすべきタイミングはいつか。ホームページの手順の写しでも、モデルカードの深掘りでもありません。それらは [ホームページ](/) と [Krea2 Edit Model](/blog/krea2-edit-model) にあります。

## Krea2 Edit サイトとは（そして何ではないか）

Krea2 Edit は **コミュニティの玄関口** です。ドメインが、ライブな Hugging Face Space、短いオリエンテーション、法務ページ、ブログをひとまとめにし、製品名で検索した人が筋の通った場所にたどり着けるようにしています。

**次のものではありません**：

- 公式 Krea.ai 製品、または krea.ai のリブランド
- 固定した重み、LoRA スタック、バッチグラフが必要なときの ComfyUI の代替
- 基盤 LoRA を当社が訓練・所有しているという主張——クレジットは公開リリース [conradlocke/krea2-identity-edit](https://huggingface.co/conradlocke/krea2-identity-edit) とその作者に残ります

Krea2 Edit を「地図＋待合室」と考えてください。到着し、ページ内でエディターを試し、ブラウザに留まるかローカルスタックへ進むか決めます。

## Krea2 Edit サイトの想定ユーザー

### プロンプトを試したい人

数 GB の checkpoint を落とす前に文言を試したい。Krea2 Edit はエディターをファーストビューに置くので、ドキュメントの迷路を通らずにツールへ行けます。

### リンクを共有するチーム

覚えやすいドメイン（`krea2edit.app`）は、長い `*.hf.space` URL より Slack で回しやすい。サイトには非公式である旨の明記もあり、Krea の商用製品と混同されにくくなります。

### インストールなしで文脈だけ欲しい読者

ComfyUI を開かない人もいます。彼らには、Krea2 Edit が「このコミュニティスタックとは何か」を動くデモの隣に置き、必要なら深い記事へ案内します。

意図的な分担です。ホームはタスク指向。ブログ（本記事や [モデルガイド](/blog/krea2-edit-model)）はナビゲーション型・調査型の検索に答え、ファーストビューを肥大化させません。

## Krea2 Edit と Space を直接開く場合

Space URL だけでも常に使えます。Krea2 Edit サイトを選ぶのは次のようなときです。

1. **ブランドの持続性** — Space のホストやバージョンが変わっても、戻る場所がひとつある
2. **周辺コンテキスト** — 法務リンク、連絡先、記事——裸の Space UI にはないもの
3. **SEO での発見性** — 製品名検索で、そのクエリ向けに設計されたページに着地できる

Gradio UI だけ気にしていてスタックを既に知っているなら、生の Space（または fork）で十分です。

## Krea2 Edit、krea.ai、ローカル ComfyUI

三者は別問題を解きます——意図的に使い分けてください。

| 行き先                      | 向いている用途                                        |
| --------------------------- | ----------------------------------------------------- |
| **Krea2 Edit**              | コミュニティ identity-edit 経路のゼロインストール試用 |
| **krea.ai**                 | 公式 Krea 製品、アカウント、アプリ内編集              |
| **ローカル ComfyUI+ノード** | 本番制御、LoRA スタック、オフライン一括処理           |

Krea2 Edit は krea.ai の再現を目指しません。ブラウザ iframe がデスクトップのグラフを置き換えるわけでもありません。多くのクリエイターが実践する流れは、Krea2 Edit で指示を試し、当たったものを固定ファイルでローカル再現することです。

## サイトの信頼性をどう保つか

- **関係の明示** — 非公式コミュニティデモ。Krea.ai, Inc. の推奨ではない
- **上流への誘導** — 重みとレシピの正本はモデルカードとノードリポジトリ
- **連絡経路** — サイトの問題は [support@krea2edit.app](mailto:support@krea2edit.app)
- **HTTPS とポリシー** — フッターに [Privacy Policy](/privacy-policy) と [Terms of Service](/terms-of-service)

埋め込み Space が壊れた場合（キュー、コールドスタート、バージョンずれ）は報告を——ホスト型デモはこのドメインのオリジンサーバーだけでなく Space の可用性に依存します。

## 新規訪問者向けのおすすめ手順

1. [Krea2 Edit](/#try) を開き、短い restage か recolor を1回——サイトが使えるか確認。
2. ホームページは必要な部分だけざっと見る。既知のセクションはスキップ。
3. この LoRA がなぜ存在するか、公式ダウンロードと何が違うか気になったら [Krea2 Edit Model](/blog/krea2-edit-model) を読む。
4. 共有 Space を超える再現性が必要になったら ComfyUI へ。

## Krea2 Edit サイトに関する FAQ

### Krea2 Edit は無料ですか？

公開サイトと埋め込みデモは無料で試せます。重みを自分でデプロイする場合は、上流 LoRA のライセンスが依然適用されます——モデルカードと Krea 2 Community License を参照してください。

### 編集に Krea2 Edit のアカウントは必要ですか？

いいえ。ホームエディターはサインアップなしで使えます。このスタックのアカウントは将来のダッシュボード機能用で、iframe のゲートではありません。

### サイトは画像を保存しますか？

埋め込み Space は第三者ホストのデモと考えてください。非公開や商用パイプラインには、自分で制御できるローカル ComfyUI グラフを優先してください。サイトレベルの方針は Privacy Policy にあります。

### フィードバックはどこへ？

サイト、ドメイン、埋め込みの問題：[support@krea2edit.app](mailto:support@krea2edit.app)。モデル訓練や LoRA のバグは Hugging Face のモデルディスカッションへ。この受信箱ではありません。
